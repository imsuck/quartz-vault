CRDT allows [[Decentralization|decentralized]] collaborative work by enforcing constraints on how edits are merged. Specifically, the merging operations need to be [[Commutative|commutative]] and [[Associative|associative]]. These constraints allow each replicas to be _eventually consistent_ once they communicate with each other.
