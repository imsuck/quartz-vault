We don't have much screen estate. Because of this a dropdown style that has some list opened up by default can feel claustrophobic. Additionally, the "Save"/"Discard" buttons are very accessible which adds more friction to editing a task details.
Suggestion:
- Move "Save"/"Discard"/"Duplicate" up next to the card title edit, use icons instead of raw text to reduce space usage.
- Split scheduling, organization, details into tabs instead of collapsible elements.
